The problem

In Russia, TSPU blocks Discord, YouTube, Twitter, Instagram, Facebook, Telegram, Roblox, Riot Games, Crunchyroll — the list grows weekly.

Existing tools (GoodbyeDPI, Zapret, ByeDPI) need you to be a network engineer: pick a config, edit flags, restart on every ISP change. When TSPU changes rules — your config is suddenly useless and you need to find new flags on Telegram channels at 2 AM.

The solution

Svoboda is autonomous. You launch it. It does the rest.

  • Detects your ISP and DPI type
  • Tries community strategies first (instant if anyone solved it)
  • Falls through 7 layers of fallback automatically
  • Asks an LLM to invent new flags if nothing else works
  • Monitors 24/7 and re-adapts when TSPU changes rules
  • Shares wins with the community anonymously

The Smart Bypass Chain

When something is blocked, Svoboda escalates through 7 layers — automatically.

1

Community Database

Another user on your ISP already found a strategy → applied in 5 seconds.

2

Local Cache

Strategy that worked on this machine before — verified and re-applied.

3

AI Advisor

Top-4 from learned memory, ranked by past fitness on similar ISPs.

4

Enumerator

75+ hardcoded + live-harvested configs from Flowseal/zapret-discord-youtube.

5

AI Strategy Engineer NEW

LLM analyzes raw symptoms (curl exit codes, latency, ISP) and invents a NOVEL flag combination not in any list.

6

ByeDPI Layer 2 NEW

SOCKS5 userspace desync — different attack model than packet-level zapret. Often pierces TSPU MITM.

7

Genetic Evolution

Geneva-style mutations of the best strategy found so far — last resort.

Once a strategy is found, it's monitored 24/7, shared anonymously with the community DB, and re-tested if connectivity degrades.
